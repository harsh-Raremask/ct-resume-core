# CT Core-30 Days Courses Suggestion (Gap Recovery)

Upload a resume → get an ATS score, skill-gap map, technology roadmap, hand-picked free
YouTube courses and a personalised 30-day career-comeback plan.

Theme: sky blue (`#0284c7` / `#0ea5e9`) + white. Theme tokens live in `src/index.css`
(`--color-brand`, `--color-brand-dark`, `--color-ink`).

## Run
```
npm install
npm run dev
npm run build
```
